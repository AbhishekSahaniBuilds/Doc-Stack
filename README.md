
# Doc-Stack

### Documenting Every Build.

A centralized documentation hub for projects, technologies, implementation details, and development notes.

Built with **VitePress**, Doc-Stack organizes technical knowledge into a structured, accessible, and searchable website.

## Features

- Project documentation and technical explanations.
- Technology references and implementation notes.
- Organized Markdown documentation.
- Sidebar navigation and local search.
- Automated deployment using GitHub Actions.
- Static website hosting through GitHub Pages.

## Technology Stack

| Technology | Purpose |
|---|---|
| VitePress | Documentation framework |
| Markdown | Documentation content |
| TypeScript | Configuration |
| Vue | VitePress framework |
| Git & GitHub | Version control |
| GitHub Actions | Automated deployment |
| GitHub Pages | Website hosting |

## Run Locally

```bash
git clone https://github.com/AbhishekSahaniBuilds/Doc-Stack.git
cd Doc-Stack
npm install
npm run docs:dev
```

## Build

```bash
npm run docs:build
npm run docs:preview
```

## Deployment

Doc-Stack uses GitHub Actions to automatically build and deploy the website to GitHub Pages whenever changes are pushed to the `main` branch.
